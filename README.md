# Oficina Frontend (Angular 20, responsivo)

- Angular 20 standalone
- Angular Material
- Layout responsivo (sidebar recolhível em telas pequenas)
- Paleta azul/verde inspirada na UnB
- CRUD de Oficinas e Carros integrado ao backend Spring Boot (`/api/oficinas`, `/api/carros`)

## Rodar localmente

```bash
npm install
npm start
```

App: http://localhost:4200

## Backend
Ajuste `src/environments/environment.ts` se o backend não estiver em `http://localhost:8080/api`.
